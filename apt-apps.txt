# ---------------------------------------------------------------------------
# apt-apps.txt - the package set installed by setup-dotFiles.sh on Debian 13
# (trixie).
#
# One package name per line. Blank lines and #-comments are ignored, so
# annotating this file is free. The reader is:
#
#     grep -vE '^[[:space:]]*(#|$)' apt-apps.txt
#
# Every surviving name is handed to a single `apt-get install` transaction,
# and apt-get refuses the WHOLE transaction on one unknown name; the script
# then retries one package at a time and names the ones that failed. Check a
# name with `apt-cache policy <name>` before you add it.
#
# This list mirrors yay-apps.txt on the master (Arch) branch. Where Debian
# names a package differently the comment says so; where Debian has no
# package at all, or installing it would do something the Arch package does
# not (start a service on install), the package is listed in the "not here"
# notes at the end of its section instead.
#
# Everything comes from trixie main; the stock sources.list is enough.
# ---------------------------------------------------------------------------
